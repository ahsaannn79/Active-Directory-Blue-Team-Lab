# 🔎 Splunk Detection Queries

This directory contains Splunk searches created for the Active Directory Blue Team Home Lab.

The queries are based on the Windows authentication and security telemetry investigated during the attack simulations performed in the lab.

## Detection Scenarios

- Password Spraying
- AS-REP Roasting
- Pass-the-Hash

These searches are intended for educational use within the controlled lab environment and may require field-name adjustments depending on the Splunk configuration and Windows event format.
